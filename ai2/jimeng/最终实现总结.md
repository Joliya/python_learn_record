## 📋 实现概述

### 核心实现：两步骤流程

根据接口文档要求，数字人快速模式必须分为两个独立步骤：

#### 步骤1：图片主体识别
- **API**: `CVProcess`
- **req_key**: `high_aes_general_v20_L`
- **作用**: 识别并处理输入图片中的人物主体
- **返回**: 处理后的图片URL或task_id

#### 步骤2：视频生成
- **API**: `SubmitTaskAsync`
- **req_key**: `avatar_video_fast`
- **作用**: 使用识别后的图片生成数字人视频
- **返回**: 视频生成任务ID

#### 任务查询
- **API**: `QueryAsyncTaskResult`
- **作用**: 查询图片识别或视频生成任务的状态
- **返回**: 任务状态、进度和结果

## 🎨 三种驱动模式

### 1. 音频驱动（AUDIO）
```python
result = client.generate_avatar_and_wait(
    image_url="https://example.com/avatar.jpg",
    drive_mode=AvatarDriveMode.AUDIO.value,
    audio_url="https://example.com/speech.mp3"
)
```

**适用场景**：
- 已有录制好的音频文件
- 需要精确控制语音内容
- 多语言场景

### 2. 文本驱动（TEXT）- 最常用
```python
result = client.generate_avatar_and_wait(
    image_url="https://example.com/avatar.jpg",
    drive_mode=AvatarDriveMode.TEXT.value,
    text="要说的内容",
    voice_type="zh_female_qingxin"
)
```

**适用场景**：
- 动态文本内容
- 快速生成
- 需要选择不同声音

### 3. 视频驱动（VIDEO）
```python
result = client.generate_avatar_and_wait(
    image_url="https://example.com/avatar.jpg",
    drive_mode=AvatarDriveMode.VIDEO.value,
    video_url="https://example.com/driving_video.mp4"
)
```

**适用场景**：
- 动作迁移
- 表情复制
- 姿态模仿

## ⚠️ 重要提示

### 1. 必须按顺序执行
```python
# ✅ 正确
detection → video_generation

# ❌ 错误
video_generation（跳过detection）
```

### 2. 使用识别后的图片
```python
# ✅ 正确
processed_image_url = detection_result['data']['image_url']
submit_avatar_video_generation(image_url=processed_image_url)

# ❌ 错误
submit_avatar_video_generation(image_url=original_image_url)
```

### 3. 任务ID的区别
- **detection_task_id**：图片识别任务（可能不存在）
- **video_task_id**：视频生成任务（总是存在）

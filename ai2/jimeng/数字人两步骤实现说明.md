# 数字人快速模式 - 两步骤实现说明

## 📋 实现概述

根据火山引擎接口文档，数字人快速模式分为**两个独立步骤**：

### 步骤1：图片主体识别
- **目的**：识别并处理输入图片中的人物主体
- **API**: `CVProcess` (Action)
- **req_key**: `high_aes_general_v20_L`
- **处理方式**：可能是同步或异步返回

### 步骤2：视频生成
- **目的**：使用识别后的图片生成数字人视频
- **API**: `SubmitTaskAsync` (Action)
- **req_key**: `avatar_video_fast`
- **处理方式**：异步任务，需要轮询查询

### 1. submit_avatar_image_detection()
```python
def submit_avatar_image_detection(self, image_url: str) -> Dict[str, Any]:
    """
    步骤1：提交图片主体识别任务
    
    Args:
        image_url: 数字人图片URL或base64编码
        
    Returns:
        包含task_id或直接返回识别结果的响应字典
    """
```

**请求参数**：
```json
{
  "Action": "CVProcess",
  "Version": "2022-08-31",
  "req_key": "high_aes_general_v20_L",
  "image_url": "https://example.com/avatar.jpg"
}
```

**返回结果**：
- 同步返回：`{"data": {"image_url": "处理后的图片URL"}}`
- 异步返回：`{"task_id": "xxx"}`

### 3. query_avatar_task()
```python
def query_avatar_task(self, task_id: str) -> Dict[str, Any]:
    """
    查询数字人任务状态（图片识别或视频生成）
    
    Args:
        task_id: 任务ID
        
    Returns:
        任务状态信息字典
    """
```

**请求参数**：
```json
{
  "Action": "QueryAsyncTaskResult",
  "Version": "2022-08-31",
  "task_id": "xxx"
}
```

**返回结果**：
```json
{
  "status": "success",  // 或 "processing", "failed"
  "progress": 100,
  "data": {
    "video_url": "https://...",
    "image_url": "https://..."
  },
  "message": "任务完成"
}
```

### 4. generate_avatar_video()
```python
def generate_avatar_video(
    self,
    image_url: str,
    drive_mode: str = AvatarDriveMode.AUDIO.value,
    ...
) -> Dict[str, Any]:
    """
    生成数字人视频（快速模式 - 完整流程）
    
    执行完整的两步骤流程：
    1. 提交图片主体识别任务并等待完成
    2. 使用识别结果提交视频生成任务
    
    Returns:
        包含video_task_id的响应字典（仅提交，不等待）
    """
```

**执行流程**：
```
输入图片URL
    ↓
步骤1: 提交图片识别
    ↓
等待识别完成（如果是异步）
    ↓
获取处理后的图片URL
    ↓
步骤2: 提交视频生成
    ↓
返回视频任务ID
```

### 5. generate_avatar_and_wait()
```python
def generate_avatar_and_wait(

    image_url: str,
    drive_mode: str = AvatarDriveMode.AUDIO.value,
    ...
    max_wait_time: int = 600,
    poll_interval: int = 5,
    progress_callback: Optional[callable] = None,

    """
    一键生成数字人视频并等待完成（推荐使用）
```

**执行流程**：
```
输入图片URL
    ↓
调用 generate_avatar_video()
  ├─ 步骤1: 图片识别
  └─ 步骤2: 视频生成（返回task_id）
    ↓
轮询查询视频生成状态
    ↓
返回最终结果（包含video_url）
```

## 📊 完整流程图

```
用户调用 generate_avatar_and_wait()
    │
    ├─ 步骤1: 图片主体识别
    │   │
    │   ├─ 调用 submit_avatar_image_detection()
    │   │   └─ POST /CVProcess
    │   │       req_key: high_aes_general_v20_L
    │   │
    │   ├─ 判断返回类型
    │   │   ├─ 同步: 直接获取处理后图片URL
    │   │   └─ 异步: 轮询 query_avatar_task()
    │   │       └─ POST /QueryAsyncTaskResult
    │   │
    │   └─ 获得: processed_image_url
    │
    ├─ 步骤2: 视频生成
    │   │
    │   ├─ 调用 submit_avatar_video_generation()
    │   │   └─ POST /SubmitTaskAsync
    │   │       req_key: avatar_video_fast
    │   │       image_url: processed_image_url
    │   │       + 驱动参数 (audio_url/text/video_url)
    │   │
    │   └─ 获得: video_task_id
    │
    └─ 步骤3: 等待视频生成完成
        │
        └─ 轮询 query_avatar_task(video_task_id)
            └─ POST /QueryAsyncTaskResult
            │
            ├─ status = "processing" → 继续等待
            ├─ status = "success" → 返回结果
            └─ status = "failed" → 抛出异常
```

## 🔍 关键点说明

### 1. 两步骤独立性
- 图片识别和视频生成是**两个独立的API调用**
- 每个步骤都有自己的任务ID
- 步骤2依赖步骤1的结果（处理后的图片URL）

### 2. 同步vs异步
- **图片识别**：可能同步返回或异步返回
- **视频生成**：始终是异步任务

### 3. 任务查询
- 使用统一的 `query_avatar_task()` 方法
- 通过 `Action: QueryAsyncTaskResult` 查询
- 支持查询图片识别和视频生成两种任务

### 4. 状态判断
```python
status = result.get('status')
if status == 'success':
    # 任务成功
elif status == 'processing' or status == 'pending':
    # 继续等待
elif status == 'failed':
    # 任务失败
```

---

## ⚠️ 注意事项

1. **图片识别超时**：默认最多等待60秒
2. **视频生成超时**：默认最多等待600秒（10分钟）
3. **轮询间隔**：建议2-5秒，避免过于频繁
4. **错误处理**：每个步骤都需要检查错误
5. **资源清理**：使用完毕后关闭session

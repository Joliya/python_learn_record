# 数字人快速模式功能更新说明

## 更新时间
2025年10月21日

## 更新内容

### 1. 新增枚举类

#### AvatarDriveMode（数字人驱动模式）
```python
class AvatarDriveMode(Enum):
    AUDIO = "audio"   # 音频驱动
    VIDEO = "video"   # 视频驱动
    TEXT = "text"     # 文本驱动（TTS）
```

#### AvatarQuality（数字人视频质量）
```python
class AvatarQuality(Enum):
    LOW = "low"       # 低质量，快速生成
    MEDIUM = "medium" # 中等质量
    HIGH = "high"     # 高质量
    ULTRA = "ultra"   # 超高质量
```

### 2. 新增核心方法

#### generate_avatar_video()
提交数字人视频生成任务。

**功能特性：**
- 支持三种驱动模式：音频、文本、视频
- 灵活的质量和分辨率设置
- 支持背景音乐
- 支持自定义参数扩展

**使用示例：**
```python
result = client.generate_avatar_video(
    image_url="https://example.com/avatar.jpg",
    drive_mode=AvatarDriveMode.AUDIO.value,
    audio_url="https://example.com/speech.mp3",
    quality=AvatarQuality.HIGH.value
)
```

#### generate_avatar_and_wait()
一键生成数字人视频并等待完成（推荐使用）。

**功能特性：**
- 自动提交任务并等待完成
- 支持进度回调
- 自动错误处理
- 超时保护

**使用示例：**
```python
result = client.generate_avatar_and_wait(
    image_url="https://example.com/avatar.jpg",
    drive_mode=AvatarDriveMode.TEXT.value,
    text="大家好，我是AI数字人！",
    progress_callback=lambda tid, prog, status: print(f"进度: {prog}%")
)
```

### 3. 新增便捷函数

#### create_avatar_video()
全局便捷函数，快速创建数字人视频。

**使用示例：**
```python
from jimeng_video import create_avatar_video

result = create_avatar_video(
    access_key="your_ak",
    secret_key="your_sk",
    image_url="https://example.com/avatar.jpg",
    drive_mode="text",
    text="快速创建数字人视频",
    save_path="./output/avatar.mp4"
)
```

## 三种驱动模式详解

### 1. 音频驱动模式（AUDIO）

**适用场景：**
- 已有录制好的音频文件
- 需要精确控制语音内容
- 多语言场景

**使用方法：**
```python
result = client.generate_avatar_and_wait(
    image_url="https://example.com/avatar.jpg",
    drive_mode=AvatarDriveMode.AUDIO.value,
    audio_url="https://example.com/speech.mp3"
)
```

### 2. 文本驱动模式（TEXT）

**适用场景：**
- 需要快速生成语音
- 动态文本内容
- 需要选择不同声音类型

**使用方法：**
```python
result = client.generate_avatar_and_wait(
    image_url="https://example.com/avatar.jpg",
    drive_mode=AvatarDriveMode.TEXT.value,
    text="要说的文本内容",
    voice_type="zh_female_qingxin"
)
```

### 3. 视频驱动模式（VIDEO）

**适用场景：**
- 需要复制特定动作
- 表情迁移
- 动作模仿

**使用方法：**
```python
result = client.generate_avatar_and_wait(
    image_url="https://example.com/avatar.jpg",
    drive_mode=AvatarDriveMode.VIDEO.value,
    video_url="https://example.com/driving_video.mp4"
)
```

## 质量等级对比

| 质量等级 | 生成速度 | 视频质量 | 适用场景 |
|---------|---------|---------|---------|
| LOW | 最快 | 基础 | 快速预览、测试 |
| MEDIUM | 较快 | 良好 | 日常使用、社交媒体 |
| HIGH | 中等 | 优秀 | 正式发布、商业用途 |
| ULTRA | 较慢 | 顶级 | 专业制作、高端应用 |

## 错误处理

### 常见错误及解决方案

1. **ValueError: 音频驱动模式下必须提供audio_url**
   - 原因：使用audio模式但未提供audio_url
   - 解决：确保传入audio_url参数

2. **ValueError: 文本驱动模式下必须提供text**
   - 原因：使用text模式但未提供text
   - 解决：确保传入text参数

3. **TimeoutError: 任务等待超时**
   - 原因：任务处理时间超过max_wait_time
   - 解决：增加max_wait_time或降低质量等级

4. **API错误: xxx**
   - 原因：API返回错误
   - 解决：检查参数格式、账户权限、配额等

# 即梦AI视频生成接入更新说明

## 主要改动

根据火山引擎API文档的实际规范，已更新API调用方式。

### 1. API调用方式修正

**之前（错误）：**
- 使用不同的endpoint进行不同操作
- `/api/v1/video/generate` 提交任务
- `/api/v1/video/query` 查询任务

**现在（正确）：**
- 使用统一的endpoint: `https://visual.volcengineapi.com`
- 通过 `Action` 参数区分操作:
  - `Action=SubmitTask` - 提交视频生成任务
  - `Action=GetVideoResult` - 查询任务结果
- 包含 `Version=2022-08-31` 参数

### 2. 认证方式修正

**之前（错误）：**
```python
client = JimengVideoClient(
    api_key="your_api_key",
    api_secret="your_api_secret"  # 可选
)
```

**现在（正确）：**
```python
client = JimengVideoClient(
    access_key="your_access_key",  # 火山引擎AK
    secret_key="your_secret_key"   # 火山引擎SK
)
```

### 3. 签名机制

新增了火山引擎签名v4算法支持：
- 自动计算请求签名
- 包含时间戳和区域信息
- 使用 HMAC-SHA256 算法
- 自动添加 `Authorization` 头部

### 4. 请求格式

**请求示例：**
```json
{
    "Action": "SubmitTask",
    "Version": "2022-08-31",
    "req_key": "{\"req_key\":\"一只可爱的小猫\",\"negative_prompt\":\"模糊\"}"
}
```

**响应格式：**
```json
{
    "ResponseMetadata": {
        "RequestId": "xxx",
        "Action": "SubmitTask",
        "Version": "2022-08-31",
        "Service": "cv",
        "Region": "cn-north-1",
        "Error": null
    },
    "Result": {
        "task_id": "xxx-xxx-xxx"
    }
}
```

## 主要改进

### 1. 完整的签名支持
- 实现了火山引擎标准的签名v4算法
- 自动处理签名计算和请求头生成
- 支持跨区域调用

### 2. 错误处理增强
- 检查 `ResponseMetadata.Error` 字段
- 提供详细的错误信息
- 自动抛出有意义的异常

### 3. 参数规范化
- 使用火山引擎标准的参数命名
- `access_key` / `secret_key` 替代 `api_key`
- 添加 `service` 和 `region` 参数

### 4. 文档更新
- 更新了所有示例代码
- 添加了密钥获取指引
- 说明了API调用机制

## 使用示例

### 最简单的方式

```python
from ai2.jimeng import create_video

result = create_video(
    access_key="your_access_key",
    secret_key="your_secret_key",
    prompt="一只可爱的小猫在花园里玩耍",
    save_path="cat.mp4"
)
```

### 标准方式

```python
from ai2.jimeng import JimengVideoClient, VideoStyle

client = JimengVideoClient(
    access_key="your_access_key",
    secret_key="your_secret_key"
)

result = client.generate_and_wait(
    prompt="夕阳下的海滩",
    style=VideoStyle.CINEMATIC.value
)

print(f"视频URL: {result['video_url']}")
```

## 获取密钥

访问 [火山引擎密钥管理](https://console.volcengine.com/iam/keymanage/) 获取:
- Access Key (AK)
- Secret Key (SK)

## 兼容性说明

**不兼容变更：**
- 初始化参数从 `api_key` 改为 `access_key` 和 `secret_key`
- 需要同时提供 AK 和 SK，不再支持可选
- API endpoint 和请求格式已完全更改

**迁移方法：**
```python
# 旧代码
client = JimengVideoClient(api_key="xxx")

# 新代码
client = JimengVideoClient(
    access_key="your_ak",
    secret_key="your_sk"
)
```

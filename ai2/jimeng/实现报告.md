## 🎯 功能特性

### 1. 三种驱动模式

#### 音频驱动 (AUDIO)
```python
result = client.generate_avatar_and_wait(
    image_url="https://example.com/avatar.jpg",
    drive_mode=AvatarDriveMode.AUDIO.value,
    audio_url="https://example.com/speech.mp3"
)
```

**特点**:
- 使用已有音频文件
- 精确控制语音内容
- 支持多语言

#### 文本驱动 (TEXT)
```python
result = client.generate_avatar_and_wait(
    image_url="https://example.com/avatar.jpg",
    drive_mode=AvatarDriveMode.TEXT.value,
    text="大家好，我是AI数字人！",
    voice_type="zh_female_qingxin"
)
```

**特点**:
- 自动TTS语音合成
- 支持多种声音类型
- 动态文本内容

#### 视频驱动 (VIDEO)
```python
result = client.generate_avatar_and_wait(
    image_url="https://example.com/avatar.jpg",
    drive_mode=AvatarDriveMode.VIDEO.value,
    video_url="https://example.com/driving_video.mp4"
)
```

**特点**:
- 动作迁移
- 表情复制
- 姿态模仿

### 2. 四个质量等级

| 等级 | 值 | 速度 | 质量 | 适用场景 |
|-----|---|------|------|---------|
| LOW | "low" | 最快 | 基础 | 快速预览 |
| MEDIUM | "medium" | 较快 | 良好 | 日常使用 |
| HIGH | "high" | 中等 | 优秀 | 正式发布 |
| ULTRA | "ultra" | 较慢 | 顶级 | 专业制作 |

## 🔧 技术实现

### API调用流程

```
用户调用
    ↓
generate_avatar_video()
    ↓
参数验证
    ↓
构建请求体
    ├── req_key: 'jimeng_avatar_fast'
    ├── image_url
    ├── drive_mode
    ├── quality
    ├── resolution
    └── 驱动源参数 (audio_url/text/video_url)
    ↓
签名认证 (_get_headers)
    ↓
发送POST请求
    ↓
解析响应
    ↓
返回结果 (task_id)
```

### 参数验证逻辑

```python
if drive_mode == "audio" and not audio_url:
    raise ValueError("音频驱动模式下必须提供audio_url")

if drive_mode == "text" and not text:
    raise ValueError("文本驱动模式下必须提供text")

if drive_mode == "video" and not video_url:
    raise ValueError("视频驱动模式下必须提供video_url")
```

### 请求体结构

```json
{
  "Action": "SubmitTask",
  "Version": "2022-08-31",
  "req_key": "{
    \"req_key\": \"jimeng_avatar_fast\",
    \"image_url\": \"https://example.com/avatar.jpg\",
    \"drive_mode\": \"text\",
    \"text\": \"大家好\",
    \"quality\": \"high\",
    \"resolution\": \"1080p\"
  }"
}
```

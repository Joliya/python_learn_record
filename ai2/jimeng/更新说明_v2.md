# 数字人快速模式 v2.0 更新说明

## 🔄 重大更新

根据火山引擎接口文档的实际要求，重新实现了数字人快速模式，采用**正确的两步骤流程**。

---

## ❌ v1.0 的问题

### 错误的实现方式
```python
# v1.0 - 错误：一次性提交，使用错误的参数
def generate_avatar_video(self, image_url, drive_mode, ...):
    req_data = {
        'req_key': 'jimeng_avatar_fast',  # ❌ 错误的req_key
        'image_url': image_url,
        'drive_mode': drive_mode,
        ...
    }
    # 一次性提交，期望直接返回结果
```

### 问题分析
1. **不符合文档要求**：文档明确说明需要两个步骤
2. **req_key错误**：使用了不存在的req_key
3. **流程错误**：跳过了图片主体识别步骤
4. **API调用错误**：使用了错误的Action

## ✅ v2.0 的改进

### 正确的两步骤实现

#### 步骤1：图片主体识别
```python
def submit_avatar_image_detection(self, image_url: str):
    """提交图片主体识别任务"""
    req_data = {
        'req_key': 'high_aes_general_v20_L',  # ✅ 正确
        'image_url': image_url,
    }
    data = {
        'Action': 'CVProcess',  # ✅ 正确的Action
        'Version': '2022-08-31',
    }
    # 返回识别结果或task_id
```

#### 步骤2：视频生成
```python
def submit_avatar_video_generation(self, image_url, drive_mode, ...):
    """提交数字人视频生成任务"""
    req_data = {
        'req_key': 'avatar_video_fast',  # ✅ 正确
        'image_url': image_url,  # 使用步骤1识别后的图片
        # + 驱动参数
    }
    data = {
        'Action': 'SubmitTaskAsync',  # ✅ 正确的Action
        'Version': '2022-08-31',
    }
    # 返回video_task_id
```

#### 任务查询
```python
def query_avatar_task(self, task_id: str):
    """查询任务状态（图片识别或视频生成）"""
    data = {
        'Action': 'QueryAsyncTaskResult',  # ✅ 统一的查询接口
        'Version': '2022-08-31',
        'task_id': task_id
    }
    # 返回任务状态和结果
```
